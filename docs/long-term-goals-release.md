# 长期目标版本 1.1.0+2

日期：2026-10-19。本文件说明代码、接口和发布产物；生成安装包不表示已经替换线上服务或已安装到设备。

## 功能

- 手机新增“长期目标”页签，宽屏 Web / Windows 左侧常驻任务池。
- 目标可拆分子任务，任务池统一选取到“我的一天”。三个入口共用同一个子任务及完成状态。
- 目标与子任务分别设置可空截止日期；过期保留、删除线、排序靠后，仍可编辑、完成或手动删除。
- 目标进度按完成子任务数量计算；取消完成、新增或删除子任务都会更新进度。
- 删除长期目标会级联删除全部子任务，以及这些子任务在所有日期的每日关联。普通每日任务、任务模板和便签不受影响。
- 全部任务日期统一在北京时间凌晨 **04:00** 切换。凌晨 00:00–03:59 算前一任务日；例如 10 月 19 日截止的任务，在 10 月 20 日 04:00 才过期。

## 升级顺序

1. 备份生产数据库、后端源码与二进制、Web 静态文件。
2. 在 Todo 数据库执行后端 `migrations/001_long_term_goals.sql`；迁移允许重复运行，不重写历史日期，不改变 MySQL 全局时区。
3. 更新后端源码或已验证的同服务器发布二进制，重启 `todo-backend`，确认服务健康。
4. 更新 Web 静态目录 `/var/www/todo_web`，让浏览器刷新新版本。
5. 手机安装新版 APK；Windows 解压完整发布目录，运行其中的 `todo_client.exe`。不要只复制 EXE，也不要直接覆盖正在运行的旧程序。

前端的连接地址和原有共享文件下载接口保持兼容。旧后端未升级时，新的长期目标接口不可用。

## 回退

优先恢复备份的后端二进制和 Web 文件；新增目标表、可空关联列和索引可保留，旧程序会忽略。不要为了回退删除新增目标数据。既有每日记录的 `target_date` 保持原值；切换旧后端会同时恢复它原来的日期规则。

## 验证

- Flutter 测试覆盖：任务完成双向同步、删除失败保留数据、旧请求不能恢复已删目标、手机与宽屏布局、删除确认、可空日期、北京时间 04:00 边界及现有 Android 下载通道。
- 隔离 MySQL / Drogon 联调覆盖：9 个新增接口、权限隔离、参数校验、并发重复选取、跨天再次选取、完成与撤销、过期排序、数据库级联删除所有日期的关联，以及普通任务池、每日任务与便签兼容。
- API 文档：`backend-api.md`，包含全部 32 个接口。

源码调整集中在目标模型、Provider、首页导航、任务池与每日页面、新增目标页面和组件；后端新增目标控制器、日期/目标辅助代码和数据库迁移，并扩展每日任务控制器。
