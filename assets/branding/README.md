# GTD 二次元任务助手图标

`app_icon.png` 是通过内置 imagegen 生成的原始图稿，同时用于登录页。
平台图标保留原有文件名和引用，包含 Android、iOS、macOS、Windows 和 Web。

在 Windows 项目根目录执行 `pwsh -File tool/update_icons.ps1`，可从原图重新生成各平台尺寸和包含七种尺寸的 Windows ICO。脚本使用系统自带的 System.Drawing，无需增加 Flutter 依赖。

## 生成提示词

Use case: stylized-concept. Asset type: production square application icon for GTD-Master, a Flutter personal todo and notes app with a deep-purple theme. Primary request: an original anime chibi task assistant portrait, friendly anime girl with short lavender hair, expressive purple eyes, a small checkmark hair clip, holding a simple small task card with one prominent checkmark. Polished Japanese anime cel-shaded illustration with bold clean outlines and simplified large shapes for legibility at app-icon sizes. Close-up centered head and shoulders, character fills most of the square, all important face details inside central 65 percent safe area. Deep purple and lavender palette, soft pale lilac solid full-bleed opaque background. One character, cheerful and calm expression. Flat frontal icon artwork only, exactly square 1024x1024. No lettering, no words, no watermark, no device mockup, no outer frame, no rounded corners, no complex scenery.
